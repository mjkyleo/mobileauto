# 手机自动化工作台

一个 PC 端手机自动化工具。连接安卓手机后，可以在电脑上实时查看手机画面、执行自动化任务、录制自己的操作并生成任务，还能把任务流程导出为可分发的 JSON 文件。

当前内置「汽水音乐 - 领时长」完整任务，开箱即用；也可以创建自己的任务。

---

## 功能特性

- **实时画面**：在电脑上查看手机屏幕，叠加可点击控件，支持返回、主页、最近任务三键
- **任务执行**：选择任务一键启动，实时显示每一步操作，随时停止
- **行为录制**：开启后可以录制点击、采集、按键等操作，录完可编辑步骤并转成任务；按钮识别不到时，可直接在画面上选点或框选
- **任务管理**：多个任务独立管理，支持新建、编辑、启停、删除、直接执行
- **流程可视化**：每个任务都能看到流程图，支持缩放、平移，并可导出为 JSON 文件
- **回放分析**：自动统计任务执行记录，查看动作分布、成功率和最近事件
- **记录文件**：统一查看运行中产生的日志、页面截图和采集数据

## 快速开始

### 1. 手机设置（只需一次）

1. 打开手机「设置 → 关于手机」，连续点击「版本号」7 次以上，开启开发者模式
2. 返回设置，进入「开发者选项」，开启：
   - **USB 调试**
   - **USB 调试（安全设置）**或**允许模拟点击**（小米、vivo 等机型需要）
3. 用数据线连接电脑，手机弹窗中选择「始终允许」并确定

### 2. 启动工作台

1. 确保电脑已安装 Python 3
2. 双击项目目录下的 **`启动工作台.bat`**
3. 首次运行会自动安装缺少的依赖，按提示等待即可
4. 工作台会自动扫描并连接手机，界面上方显示连接状态

> Windows 系统需要 Edge WebView2 运行环境，Win10/11 通常已自带；若缺失，按提示安装即可。

### 3. 执行任务

1. 在「设备工作台」页面顶部选择任务（默认已选中「汽水音乐 - 领时长」）
2. 点击「执行任务」
3. 手机屏幕下方「执行过程」会实时显示正在做的每一步
4. 需要停止时，点「停止任务」或直接关闭窗口

> 独立的命令行窗口方式：双击 **`刷时长_看过程.bat`**，功能与工作台任务一致，适合只看运行过程。

## 使用指南

### 设备工作台

- **设备状态**（左侧）：查看连接状态，手动扫描、刷新、断开、诊断
- **实时画面**：手机真实屏幕；下方的返回 / 主页 / 最近键可直接操作手机
- **执行过程**：固定窗口显示最近操作，可滚动查看全部历史
- **行为录制**（右侧）：
  - 点「开始录制」后，正常点击按钮、采集页面、按系统键都会被记录
  - 识别不到按钮时，点「选点 / 框选」，在实时画面上单击定位或拖拽框选区域
  - 录制步骤可改名、改动作、改坐标、试点击、排序、删除
  - 重复动作可点「折叠循环」合并成循环步骤
  - 点「转成任务」生成任务草稿，再到「任务列表」里编辑
- **可点击按钮**：显示当前页面识别到的按钮，点一下即可操作
- **采集当前页面**：保存当前手机截图、文字和控件信息，便于分析问题页面

### 任务列表

左侧是任务列表，点击任务即可在右侧打开该任务的 JSON 文件和流程图。

右侧提供三个标签：

- **JSON 编辑**：直接修改任务内容，并可勾选启用哪些能力
- **流程视图**：以图形方式显示任务的步骤、判断、循环和结束条件，支持缩放和平移
- **Mermaid**：显示流程图的文本源码，可复制到其他支持 Mermaid 的工具中使用

顶部按钮：

- **导出流程 JSON**：把当前任务保存为标准 `.flow.json` 文件，可选择保存位置
- **导入流程 JSON**：从文件导入任务，导入后默认停用，确认无误后再启用

每个任务对应 `tasks/` 目录下的一个 JSON 文件，彼此独立，可直接复制分发。

### 回放分析

进入该页面会自动分析任务执行日志，显示动作分布、执行结果、来源分布和最近事件。任务运行越多，这里的数据越丰富。

### 记录文件

集中查看运行时产生的日志、页面采集数据和执行记录，点击文件即可在右侧预览内容。

## 常见问题

**Q：工作台没有识别到手机？**

确认手机已开启 USB 调试并授权电脑；点左侧「设备状态」里的「诊断」查看原因；也可以在设备地址栏手动输入手机的 IP 或设备编号后重新扫描。

**Q：任务执行到一半卡住了？**

任务带有防卡死机制，会在异常页面自动尝试返回。如果仍卡住，可以点「停止任务」后重新启动，或在「记录文件」中查看对应日志。

**Q：某个按钮识别不到怎么办？**

在设备工作台点「选点 / 框选」，直接在实时画面上点击或框选按钮位置，系统会自动试点击并把这一步加入录制草稿。

**Q：任务文件保存在哪里？**

所有任务都在 `tasks/` 目录下，一个任务一个 JSON 文件。运行日志和采集数据保存在 `runtime/` 目录。

**Q：如何停止任务？**

点工作台的「停止任务」，或关闭运行窗口；命令行方式按 `Ctrl + C`。
